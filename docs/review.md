# Ревью кода

## Проверенные требования

- размеры матрицы принимаются только как натуральные числа;
- элементы преобразуются в тип `float`;
- количество элементов каждой строки проверяется;
- ошибки ввода не завершают программу аварийно;
- матрица выводится по столбцам;
- функции снабжены аннотациями типов и краткими docstring;
- основные сценарии покрыты автоматическими тестами.

## Результат

Код разделён на небольшие функции по назначению. Функция `matrix_print`
использует `zip(*matrix)`, поэтому строки исходной матрицы преобразуются в
столбцы при выводе. Тесты проверяют основную функциональность и обработку
ошибочного ввода. Критических замечаний по итогам ревью нет.
