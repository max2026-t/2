# План тестирования

Автоматические тесты находятся в каталоге `tests` и запускаются командой:

```bash
pytest -v
```

Проверяются следующие сценарии:

1. вывод прямоугольной матрицы по столбцам;
2. корректный ввод натуральных размеров;
3. повторный запрос после ошибочного размера;
4. ввод вещественных элементов;
5. повторный запрос строки при неверном количестве элементов;
6. повторный запрос строки при нечисловом значении.

GitHub Actions выполняет тесты на Python 3.9, 3.10, 3.11 и 3.12.

## QA-04-01 Логическое значение в количестве товара

Шаги: передать корректный JSON на POST /api/v1/orders/calculate, заменив
items[0].quantity на true. Ожидалось HTTP 422. Фактически до исправления API
вернул HTTP 200 и рассчитал заказ как с одной единицей товара.
Тяжесть средняя, приоритет высокий: некорректные данные влияли на сумму.
Исправление: проверка типа перед преобразованием количества в целое число.
Повторный запуск: true и false отклонены с HTTP 422.
