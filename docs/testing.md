# План тестирования

Автоматические тесты находятся в каталоге `tests` и запускаются командой:

```bash
pytest -v
```

Проверяются следующие сценарии:

1. вывод прямоугольной матрицы по столбцам;
2. корректный ввод натуральных размеров;
3. повторный запрос после ошибочного размера;
4. ввод вещественных элементов;
5. повторный запрос строки при неверном количестве элементов;
6. повторный запрос строки при нечисловом значении.

GitHub Actions выполняет тесты на Python 3.9, 3.10, 3.11 и 3.12.
