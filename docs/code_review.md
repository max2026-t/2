# Результаты инспекции кода

Проверены модули `src`, тесты и демонстрационный драйвер. Для проверки
стиля используется команда `flake8 src tests tools`. Замечаний по
неиспользуемым импортам, неопределенным именам и длине строк нет.

Во время ревью проверены следующие решения:

- денежные значения хранятся как `Decimal`, а не `float`;
- проверка JSON выполняется моделями Pydantic до вызова бизнес-логики;
- HTTP-маршрут не содержит расчета стоимости;
- исключения интеграции имеют стабильные коды и HTTP-статусы;
- версия контракта проверяется до запуска нижних модулей;
- таймаут ограничивает ожидание внутреннего сервиса;
- зависимости передаются в `OrderProcessor`, поэтому заглушки и реальные
  реализации подключаются одинаково;
- тесты не зависят от запущенного внешнего сервера.

Критических замечаний по результатам повторной проверки не осталось.
# Инспекция кода и ревью тестов ЛР 4

При повторном ревью добавлены явная таблица сочетаний условий размеров
матрицы и проверка обеих точек входа. Прямой вызов сервера и запуск как
скрипта проверяют одинаковые параметры Uvicorn, сетевой порт не открывается.
После включения сервера в область измерения flake8 и все 53 теста прошли.

Команда `python -m flake8 src tests tools` завершилась с кодом 0.
При ручной проверке контракта обнаружено несоответствие между полем количества
и фактическим приёмом JSON true. Добавлен валидатор до преобразования типа и
регрессионная проверка двух логических значений.

Самостоятельное ревью тестов: проверены независимость сценариев и соответствие
ожиданий правилам расчёта. Каждый параметризованный сценарий создаёт собственную
копию позиции заказа, использует константы для ожидаемых сумм и сверяет HTTP-код.
Успешные запросы проверяют итог и его отображение в отчёте. Ошибочные сверяют код
ошибки и путь либо поле валидации. Запуск сервера проверен с подменой uvicorn.run.
Тесты API выполняются без сетевого порта и внешних сервисов.
