# Результаты инспекции кода

Проверены модули `src`, тесты и демонстрационный драйвер. Для проверки
стиля используется команда `flake8 src tests tools`. Замечаний по
неиспользуемым импортам, неопределенным именам и длине строк нет.

Во время ревью проверены следующие решения:

- денежные значения хранятся как `Decimal`, а не `float`;
- проверка JSON выполняется моделями Pydantic до вызова бизнес-логики;
- HTTP-маршрут не содержит расчета стоимости;
- исключения интеграции имеют стабильные коды и HTTP-статусы;
- версия контракта проверяется до запуска нижних модулей;
- таймаут ограничивает ожидание внутреннего сервиса;
- зависимости передаются в `OrderProcessor`, поэтому заглушки и реальные
  реализации подключаются одинаково;
- тесты не зависят от запущенного внешнего сервера.

Критических замечаний по результатам повторной проверки не осталось.
