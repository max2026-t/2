# Архитектура проекта

Проект представляет собой небольшое консольное приложение без внешних
зависимостей времени выполнения.

## Компоненты

- `input_matrix_size` запрашивает и проверяет размеры матрицы;
- `matrix_init` считывает вещественные элементы построчно;
- `matrix_print` транспонирует представление через `zip` и выводит столбцы;
- `main` связывает этапы программы.

Исходный код расположен в `src`, автоматические тесты - в `tests`,
документация - в `docs`, а настройки GitHub Actions - в `.github/workflows`.
