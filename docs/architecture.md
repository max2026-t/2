# Архитектура проекта

В этом документе описана структура системы, взаимодействие компонентов и ключевые архитектурные решения.

## 1. Высокоуровневый обзор

**Стиль архитектуры:** микросервисы 

**Основные компоненты:**
* `domain/` — бизнес-логика, не зависит от внешних фреймворков
* `application/` — варианты использования, координирует взаимодействие между domain и инфраструктурой
* `infrastructure/` — внешние зависимости (база данных, HTTP-клиенты и т.д.)
* `interfaces/` — точки входа (веб-контроллеры, CLI и т.п.)
