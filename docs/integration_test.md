# Проверка интеграции

## Тестовая среда

Проверка выполняется командой:

```bash
coverage run -m pytest -v
coverage report --fail-under=90
```

## Сценарии

| Сценарий | Ожидаемый результат | Фактический результат |
|---|---|---|
| Запрос без скидки | итог равен сумме позиций | пройден |
| Скидка WELCOME10 | уменьшение суммы на 10 процентов | пройден |
| Первый этап со заглушками | маршрут возвращает фиксированный ответ | пройден |
| Полная цепочка REST API | код 200 и рассчитанный итог | пройден |
| Пустой список товаров | ошибка валидации 422 | пройден |
| Отрицательное количество | ошибка валидации 422 | пройден |
| Версия 2.0 | ошибка 409 version_conflict | пройден |
| Неизвестная скидка | ошибка 400 invalid_data | пройден |
| Нулевой таймаут | ошибка 504 integration_timeout | пройден |
| Отказ внутреннего сервиса | ошибка 503 module_unavailable | пройден |

В набор входят модульные тесты расчета, проверки интеграционного слоя,
тесты REST API и шесть тестов программы из предыдущих работ. Покрытие
проверяется отдельно и не может быть ниже 90 процентов.
