# Ввод матрицы по строкам и вывод по столбцам

Консольная программа запрашивает размеры матрицы `n x m`, принимает
вещественные элементы построчно и выводит их по столбцам.

## Требования

- Python 3.9 или новее;
- GNU/Linux или Windows.

## Запуск

```bash
python src/main.py
```

Пример для матрицы 2 x 3:

```text
2
3
1 2 3
4 5 6
```

Результат:

```text
1.0 4.0
2.0 5.0
3.0 6.0
```

## Проверка

```bash
pytest -v
```

## Ветвление

Используется упрощенная модель Git Flow: стабильная версия хранится в
ветке `main`, а разработка ведется в ветке `develop`. Изменения проходят
автоматические проверки и после этого объединяются с `main`.
