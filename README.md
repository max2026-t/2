# Программа для работы с матрицей
Программа, которая запрашивает размерность матрицы m * n, ее элементы построчно, а выводит по столбцам.
Требование к окружению: операционная система GNU/LINUX, Windows, процессор, интепретатор языка программирования Python.
Запустить, ввести два числа, саму матрицу.
